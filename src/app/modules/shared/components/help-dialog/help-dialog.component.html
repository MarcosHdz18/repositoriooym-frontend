Ayuda del Sistema

Bienvenido al repositorio de información de la Gerencia OYM Recepción Infraestructura, Aplicativos y Sistemas Virtualizados. Aquí puedes gestionar toda la información de los proyectos que se reciben para la puesta en operación en la red de Telcel.

  • Para crear un nuevo registro pulsa el botón “Nuevo …” en cada pantalla.
  • Para editar, usa el icono ✏️.
  • Usa el buscador para filtrar por cualquier campo del proyecto.

Versión de la app: 1.0.0
